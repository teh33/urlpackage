URLPackage Workbench
Schema Spec Example GitHub

Draft 0.1 · local browser tool

Open, edit, validate, and export link packages.

A .urlpackage.json is a portable list of websites with package metadata and per-link decorations. No account. No backend. Files stay on your machine unless you publish them.

Load from URL

Direct .urlpackage.json URL; requires CORS.

Format

Package
title, description, version, cover image, icon
Links
URL, title, description, image, tags, status, last-known-good, notes
Exports
JSON, Markdown, bookmarks HTML, static HTML
{
  "urlpackage": "0.1",
  "title": "Starter links",
  "links": [
    { "url": "https://example.com" }
  ]
}
